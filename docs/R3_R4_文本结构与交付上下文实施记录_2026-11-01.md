## R3：文本结构与事实绑定

复用现有事实投影、数量用途审计、角色及来源绑定、共同完成门。统一标题、列表、
引用、换行、括号、字段标点、inline code 和 Markdown 表格的结构与原文位置映射。
格式是表达结构，不提供业务 Evidence；同值数字不能跨字段、角色、总体或数据版本借用。
不以关键词、列表长度或模型自报数量类型豁免业务事实；不保留失败后转宽松旧路径。

| 场景 | 核心门槛 |
|---|---|
| T01 常见格式等价 | 正确画像／统计跨标题、列表、引号、软换行、括号、表格同判；原位置可追溯 |
| T02 紧邻错误 | 正确段落旁错值、错字段、错角色仍拒绝，不能借相邻事实或格式遮罩通过 |
| T03 事实角色与范围 | 前75／后38不能与互换同过；错版本、错数据集及漏筛选范围拒绝 |
| T04 中文数量 | b17、多行数量、中文月份不消失；空 claims 不能绕过数量审计 |
| T05 文档与业务数量 | 结构成员数只证明成员数；普通指代不造业务事实，错误重复／异常仍拒绝 |
| T06 跨消费者 | 聊天、完整 Verifier、报告及修复候选消费同一结构／绑定规则；不因渲染失去来源 |
| T07 真实本地路径 | 上传→画像、筛选说明及新报告走真实工具、Host、SQLite；模型可用确定性替身 |
| T08 持久版本 | 新解释有明确版本与来源映射；旧判定不重写，未知或不兼容失败关闭 |

38 条旧格式／来源登记须逐项核对实际断言。部分原样本的整篇回答本来应拒绝，
真正问题是额外伪数量；不得将“消除伪数量”误改为“整篇放行”。优先修共因及常见场景，
少见格式只有在核心影响查明、配对安全反例保留后才可延期。

## R4：上下文、交付与恢复

投影与消费边界，不建立第二事实库或 DeliveryManifest 数据库。前端仅做来源、数值和状态

| 场景 | 核心门槛 |
|---|---|

| C04 产物一致性 | 回答、表总计、图表、报告绑定相应 analysis、dataset、measure/group/unit/null policy |

## R3 接口冻结与迁移决定

- 纯语法层 `packages/common/text_surface.py` 描述原文 hash、块／引号／表格节点、
  字符位置与闭合状态；不接受模型自报用途，不判断业务事实。
- 现有 `claim_structure.statement_projections` 为唯一标题→内联→表格→分句组合；
  profile 表格用原字段格、统计表头和值格的明确关系，不能按相同数字回找来源。
- 数量契约升级为 `quantity-contract-v2`，唯一对应 `text-surface-v2`；
  报告验证标记为 `selected-artifact-quantity-v3`。不增数据库列或另一事实协议。
  原 v1、缺版本及未知版本可只读查阅，不能自动改写为新版本后继续执行。

- 报告仍先校验原源闭合／数量门，再核实际渲染文本；二者使用同一事实绑定器。

  已支持的另一个数值也不能替换原声明，增删事实须拒绝。
- 解析器失败不回退旧宽松结果。历史结果保留；修前副本与新诊断各自归档，
  后续每批版本冻结在现有 TaskContract hash 中，不能恢复时静默换规则。

## R4 实施入口与冻结裁决

R3 本地检查点为 `9741ce9e5ffed53ead81a166c5ca1cabfd8302e1`，提交后工作树干净；未推送。
R4 继承该版本，只在会话/任务/既有 Evidence、数据集绑定和产物上建立只读投影，不建立第二事实库或新增数据库 schema。

- 来源事件：本会话真实上传、可验证的明确来源选择、成功工具产生且有真实绑定的变换。最新事件失效时保持不可用，不采用项目最新或旧父数据兜底。

- 数据来源与最新任务状态分开：已成功生成 child 不等于任务 completed。暂停、待澄清、失败保持实际状态，重开 GET 不重放模型/工具。

- 只选择数据且无其他义务时允许无工具完成；冻结原请求和完整合同证明必须一致。明确撤回或无法确定来源意图时不得执行，也不得隐式恢复旧来源。
- 回答、图表默认源和默认报告分析使用同一投影。显式授权的历史分析仍可查看/生成报告，但不改变后续默认数据。Artifact.dataset_ref 保留原输入来源，不能为界面方便改成输出 child。
- 界面当前执行源与正在浏览的数据分开；表格总计只读工具 total_value，包括合法零值。count 的既有 SQL 口径为非空字段计数，不是记录数或人数。
- 数据文件仅按既有登记、可读性和 immutable ref 契约核验；本批不新增 parquet 任意字节防篡改系统。报告/产物既有 hash 验证继续保留。
