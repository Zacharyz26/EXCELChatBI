# 阶段 6D 实施记录：统计证据与预测护栏

> 状态：工程关闭；6D-1～6D-4 已通过远程完整 CI
> 更新日期：2026-08-13
> 前置：阶段 6C 已由提交 `d5005ee` 的完整 CI 关闭

## 1. 阶段目标与切片

阶段 6D 在 6C 的有界候选、人工选择和结果生命周期上补齐统计推断与预测的确定性护栏。
它继续使用固定 capability 目录、MCP Tool、Evidence Ledger 和 Verifier，不允许模型自行计算
统计量、生成隐藏分析步骤或自动扩张探索目标。

1. **6D-1 统一统计 Evidence 契约**：趋势、异常、相关和回归统一披露样本、缺失处理、方法、
   假设、多重检验、局限与因果边界；
2. **6D-2 受治理高级统计**：实现维度贡献、分群比较，并加强回归诊断和小群体保护；
3. **6D-3 独立预测能力**：以 `stats.forecast` Tool/Profile 实现训练/验证隔离、时间泄漏检测、
   误差指标和预测区间；
4. **6D-4 发布门禁**：冻结匿名代表性评测，补 React 局限展示、双传输契约等价和真实 Compose
   重启/离线恢复验证。

## 2. 6D-1 实际交付

- 新增严格 `chatbi-statistical-evidence-v1` 输出块，四类统计工具统一返回：
  `analysis_kind`、实际方法、总/有效/剔除样本量、`complete_case_drop` 缺失策略、最小样本量、
  显著性阈值、检验数量、多重检验方法、方法假设和局限；
- 相关列对和回归特征系数使用确定性 Holm 校正，`significant` 依据校正后的 p 值判断；原始 p 值
  与 `adjusted_p_value` 同时保留，数值均由 stats MCP 工具计算；
- 所有统计 Evidence 固定 `causal_claim_allowed=false`；相关结果明确“相关不等于因果”，异常
  根因只能称为候选解释因素；
- stats Tool 输出 schema 和工具版本同步升级到 1.1.0。新 TaskRun 冻结新 contract hash，
  已运行任务继续使用原有不可变目录；
- LLM 解读只接收白名单统计摘要与同一 Evidence 护栏，并在 system 约束中强制披露样本处理、
  假设和局限，不得把相关/回归改写为因果；
- Planner 将“预测”明确路由到独立 `stats.forecast`，不再用 `stats.trend` 的探索性线性外推
  伪装受治理预测；未启用 forecast Profile 或目录缺少 Tool 时失败关闭。

## 4. 6D-2 实际交付

- 新增 `stats.contribution` / `dimension_contribution`：只接受非负、可加总的 `sum` 或非空记录
  `count`，输出总量、维度值、份额、排名、展示覆盖率以及小群体保护计数；小群体按数据策略
  合并或抑制，敏感列禁止进入模型结果；
- 新增 `stats.group_compare` / `group_compare`：两群使用 Welch t，三至十群使用 Welch ANOVA；
  成对 Welch t 统一做 Holm 校正并返回 Hedges g。小群体完全抑制，不把不同群体合并成统计上
  无意义的“其他”样本；不足两群、零组内方差或群体过多均失败关闭；
- 回归最小样本量调整为 `max(10, 5 × (特征数 + 1))`，新增 Jarque-Bera 残差正态性、
  Breusch-Pagan 异方差、Durbin-Watson 自相关、condition number、VIF 和秩亏诊断；诊断只产生
  确定性告警，不自动删特征、换模型或修改用户目标；
- 两个新 Tool 均进入严格输入/输出 schema、stats 服务目录、中央 allowlist、Agent registry、
  Planner capability 路由、字段角色前置检查、兼容 API/报告和白名单模型解读；新 TaskRun 才能
  冻结并使用新目录，已运行任务不热插拔；
- 6C 开放探索的分群候选在新 capability 已声明时绑定 `stats.group_compare`；若 profile 禁用则
  明确 unavailable，不降级回普通聚合。旧冻结 6C 目录未声明该能力时仍保留兼容聚合路径；
- 贡献与分群结果继续使用 `chatbi-statistical-evidence-v1`，固定因果禁令并披露样本、小群体、
  多重检验、假设和局限。没有引入纯 React 自由循环或模型侧统计计算。

## 6. 6D-3 实际交付

- 新增独立 `stats.forecast` Tool 与严格输入/输出契约，只允许 `naive`、`drift` 和显式周期的
  `seasonal_naive` 三种确定性单变量方法；`auto` 只能在该固定候选集内按时间留出 MAE 选择，
  模型不能新增算法、修改目标或自行计算预测值；
- 输入必须是至少 12 个唯一、等间隔的有效时间点。训练记录严格早于验证记录，验证窗口至少
  覆盖预测 horizon；季节预测至少需要三个完整周期，且训练集和验证集分别满足周期覆盖要求；
- 结果固定返回 MAE、RMSE、sMAPE、可用时的 MAPE、最后值朴素基线、是否优于基线、95%
  经验绝对误差区间，以及明确的时间泄漏检查。未优于基线时 `reliability=limited`，Agent 与
  解读 Prompt 均禁止把它写成可靠预测；
- `statistical_evidence` 披露完整案例剔除、样本门槛、固定留出假设、单变量边界、区间非校准
  概率区间，以及 `auto` 在同一留出集选模与评估可能乐观的限制；原有趋势 Tool 的探索性
  `forecast_horizon` 仍不能形成受治理预测 Claim；
- Tool 已接入 stats MCP 服务、中央 allowlist、字段角色门禁、Planner、Agent Artifact/摘要、
  兼容统计/报告 API、报告渲染与模型白名单摘要。时间列或指标列受 `MASK/EXCLUDE` 保护时工具
  直接拒绝；摘要层另有策略收紧后的失效保护；
- `forecast` capability profile 默认不启用。新 TaskRun 只有在配置显式加入 `forecast` 后才能
  冻结并看到该工具；已运行 TaskRun 不热插拔。即便 Profile 已启用但工具目录缺失，也会明确
  `tool_unavailable`，不会回退为趋势外推或模型心算。
- 预测工具/Schema/Profile/Planner/角色/摘要/报告定向回归已通过；Ruff 全库、相关模块 strict
  mypy 通过，CI 等价 `hashing/lexical/local` 配置的完整后端回归为 **651 passed、2 skipped**。
  这只证明 6D-3 本地实现与回归完成，远程 backend/frontend/Compose 验证由 6D-4
  新增的发布门禁统一执行。

## 7. 6D-4 实际交付

- 冻结 14 个匿名合成预测场景，覆盖线性、常量、季节序列，日/周/月初频率，自动与显式
  方法，以及不规则时间、重复时间、样本不足、验证窗口不足、季节覆盖不足和受保护字段的
  失败关闭。评测执行真实 `stats.forecast`，但报告不保存序列值、列名、Dataset reference
  或预测值；CI 强制上传 `forecast-quality` 脱敏产物；
- 质量门禁分别约束预期结果、严格输出契约、时间泄漏检查、基线/可靠性一致性、MAPE 可用性、
  错误失败关闭和固定方法集合。包含零值的验证窗口必须返回 `mape=null`，未优于朴素基线时
  必须返回 `limited`，不能通过平均分掩盖单项越界；
- React Stats Artifact 增加预测专用展示：显式显示可靠性、朴素基线比较、留出 MAE/RMSE、
  95% 经验区间、泄漏检查、逐期点预测/上下界、统计假设与结论局限；低置信结果使用独立警示
  状态，刷新后仍从持久 Artifact 恢复；其他统计 Artifact 同步展示 Statistical Evidence；
- 新增 `forecast_recovery_probe`。Compose 发布门禁使用同一匿名固定数据，校验进程内处理器、
  官方 SDK stdio 和 Streamable HTTP 的完整 stats 目录及预测结果 hash 等价；随后重启
  `stats-tools`，要求 Gateway 连接代次递增、重新校验目录且预测结果不漂移；探针报告不包含
  原始数据或预测明细；
- 默认 Compose Profile 继续保持 `stats,browser`，只有显式加入 `forecast` 的新 TaskRun 才
  能向 Planner 暴露预测能力。服务探针验证内部 Tool 契约与传输，并不绕过 Host 的 Profile、
  计划、权限、Evidence Ledger 或 Verifier 控制。
