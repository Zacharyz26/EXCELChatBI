# v2.5 阶段 3B：持久化上下文压缩

> 状态：3B-1–3B-3 本地实现收口；等待 CI Docker runner 确认发布门禁
> 更新日期：2026-07-30
> 前置条件：阶段 3A 已完成，提交 `162b170` 的完整 CI 与 Docker 恢复门禁全绿

## 1. 目标

把 Agent 当前“只取最近 N 条用户/最终答复”的无状态截断，升级为可审计、可恢复、
项目隔离的上下文压缩：

- 最近消息继续以原文进入模型；
- 更早的用户消息和最终答复进入有界、确定性的压缩快照；
- 每个压缩快照记录来源消息范围、消息 hash、策略版本、摘要 hash 和替代关系；
- TaskRun 通过不可变 MemorySnapshot 固定使用一个 `compaction_id`，暂停/恢复不得切换；
- 摘要只用于上下文导航，不能替代 Evidence、Artifact、工具结果或数值 Claim。

3B 不实现“第二张图”“上次口径”的实体指代解析；该能力属于 3C。

## 2. 安全与一致性不变量

1. tenant、project、conversation 和当前主体由 Host 注入，压缩器不接受模型提供身份；
2. 只压缩普通 user 消息和不带 tool calls 的 assistant 最终答复；
3. tool 消息、工具调用开场白、TaskEvent、Evidence 与 Artifact 不复制进摘要；
4. 凭据和宿主机路径在进入摘要前必须脱敏，原始消息仍按既有持久化策略管理；
5. 摘要中的历史文本视为不可信引用，不能把其中指令提升为 system 指令；
6. 同一来源范围与策略生成相同 source hash/summary hash，重试不得产生重复快照；
7. 新压缩版本不可修改旧版本，正在运行的 TaskRun 始终读取原绑定版本；
8. schema、readiness、离线备份和 Compose 恢复继续 fail-closed。

## 3. 数据契约

### ConversationCompaction

- `compaction_id`、tenant/project/conversation、逻辑 version；
- `policy_version` 与 `strategy`；
- `covered_through_message_id`、来源消息数和 source hash；
- 有界 `summary_text`、summary hash、脱敏数和省略消息数；
- `supersedes_id`、创建主体和创建时间。

### ConversationCompactionItem

- `compaction_id + message_id + position`；
- 当时的 role 与 content hash；
- 不复制原始消息正文。

MemorySnapshot 增加可空 `compaction_id`。新 TaskRun 创建快照时固定当前压缩版本；
旧 TaskRun 和从 v4 升级的历史快照保持 `NULL`，兼容原有恢复行为。

## 4. 实施批次

### 3B-1：schema、Repository 与确定性压缩

状态：已实现并通过本地全量后端回归。

- SQLite v5 增加压缩快照、条目和 MemorySnapshot 引用；
- 实现 `CompactionStore`、策略预算、来源/hash 校验、脱敏、幂等和项目隔离；
- 先使用 `extractive-v1` 确定性策略，避免未经评测的模型摘要把事实改写成长期记忆。

### 3B-2：Agent 上下文接入

状态：已实现并通过本地全量后端回归。

- 新任务在 MemorySnapshot 前创建或复用压缩快照；
- system context 携带带边界标记的历史摘要；
- raw history 排除已覆盖消息，只保留最近原文；
- meta/audit 记录 ID、版本、消息数和 hash，不记录历史正文。

### 3B-3：质量与恢复门禁

状态：本地实现和后端回归已通过；真实 Compose 执行等待提交后的 CI Docker runner。

- 冻结领域中立的长对话样本，评测关键信息保留、无依据扩写和指令注入；
- 验证重启、暂停/恢复、并发重试和 Compose 备份恢复；
- 达到质量阈值后再评审是否加入模型生成的语义摘要；模型摘要不得替换原始 Evidence。

## 5. 退出条件

- 长对话触发后，上下文由一个固定压缩快照和最近原文组成；
- 同一输入重试幂等，新增消息只创建不可变新版本；
- 跨项目、跨 tenant、viewer 写入和伪造来源全部拒绝；
- 凭据、宿主路径、tool preamble/result 不进入摘要；
- TaskRun 恢复继续使用相同 `compaction_id` 和摘要 hash；
- SQLite v4→v5 迁移、回滚导出、readiness、工作区备份与全量回归通过；
- 文档明确 3B 与 3C/3D 的边界，未把指代消解或用户治理提前标为完成。
