# v2.5 阶段 3D：用户记忆治理

> 状态：3D-1–3D-3 本地实现完成；等待提交后的 CI/Compose 门禁
> 更新日期：2026-07-31
> 前置条件：3A–3C 已关闭；v2.4 G7 继续保持 `review_required`

## 1. 目标

让项目成员能够在不开放通用 `memory.write` 的前提下查看、纠正和删除自己有权治理的
长期记忆：

- owner/editor 可把生效记忆纠正为新的不可变版本；
- owner/editor 可软删除 active/conflict 记忆；
- viewer 只读，subject 记忆只对对应主体可见；
- 项目、tenant 和 conversation 边界由 Host 注入并失败关闭；
- 并发修改使用 `expected_version`，重试使用 `Idempotency-Key`；
- 历史 MemorySnapshot、TaskRun 和审计记录不因治理操作被改写。

3D 不实现自动记忆提取，也不允许模型或 MCP Server 任意创建、修改或枚举项目记忆。
计划编辑、高风险审批和完整任务控制前端仍属于阶段 4。

## 2. 安全与一致性不变量

1. API 不返回 tenant、subject、scope key、semantic key、来源引用/hash 或创建主体；
2. 修订只允许改变摘要、置信度和有效期；作用域、kind、semantic key、conversation
   和原始来源保持不变；
3. 修订生成新 `memory_id`，旧 active 版本变为 `superseded`，不原地改写正文；
4. 新版本继承旧版本的受控资源 Link，避免未来引用解析失去 Dataset/Artifact/Evidence；
5. 删除只更新生命周期状态；已固定快照继续返回当时的不可变记录 JSON；
6. 同一幂等键只能绑定同一主体、项目、操作和请求 hash；不同请求返回 `409`；
7. 版本或状态漂移返回 `409`，越权资源统一按 `404` 处理；
8. Memory Policy 继续拒绝凭据、宿主路径、越界置信度和非法时间；
9. 审计只记录 ID、版本、状态、结果和拒绝原因类型，不记录记忆摘要。

## 3. 实施批次

### 3D-1：安全治理 API

状态：本地实现完成。

- `GET /projects/{project_id}/memories`：全部生命周期分页查询，支持状态、作用域、
  kind 和 conversation 筛选；
- `GET /projects/{project_id}/memories/{memory_id}`：读取单条安全视图及受控资源关联；
- `PATCH .../{memory_id}`：用版本号和幂等键创建不可变纠正版本；
- `DELETE .../{memory_id}`：用版本号和幂等键软删除；
- Repository 在同一事务中复制旧版本 Link，并让无 conversation 筛选的治理查询包含
  项目内全部可见 conversation 记忆。

### 3D-2：React 治理入口

状态：本地实现完成。

- 对话工作区标题栏增加“项目记忆”入口；
- 抽屉展示状态、作用域、kind、版本、置信度、来源类型、有效期和关联数；
- 支持状态/作用域筛选、刷新、不可变纠正和软删除；
- 界面明确不可修改字段、历史快照语义和并发覆盖拒绝；
- token 仍只由现有 API client 添加，浏览器不接触数据库、MCP endpoint 或服务凭据。

### 3D-3：隔离、恢复和浏览器门禁

状态：本地实现完成；真实 Compose runner 待提交后确认。

- API 回归覆盖 tenant/project/subject/role 隔离和响应字段最小化；
- 覆盖幂等重放、幂等键冲突、版本冲突、Policy 拒绝和 Link 继承；
- 在治理前冻结 MemorySnapshot，确认纠正/删除后旧快照内容不变；
- 本机真实 Web/API Playwright 预置带来源记忆并完成查看、纠正、删除；
- Compose runner 继续执行 SQLite/文件离线备份恢复、固定引用和浏览器主链路。

## 4. 退出条件

- 用户能从唯一对话工作区查看、纠正和删除有权访问的记忆；
- viewer 不能治理，subject/tenant/project 不发生越界读取；
- 并发和重试不会产生覆盖更新或重复版本；
- 修订后资源关联仍可解析，历史版本和快照保持不可变；
- API 响应和审计不泄露内部隔离键、来源 hash 或正文；
- Ruff、后端完整回归、前端 lint/build、普通浏览器 E2E 和真实本机 full-stack E2E 通过；
- 提交后的 backend、frontend 和 Compose/containers CI 全绿后，才能关闭 3D。
