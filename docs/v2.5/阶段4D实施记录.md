# v2.5 阶段 4D 实施记录

> 状态：真实 Compose 场景代码已补齐；等待更新提交的 Docker/Compose CI 关闭阶段 4
> 更新日期：2026-08-03

## 1. 本阶段目标

阶段 4D 完成人机协作阶段最后三项产品能力，同时保持浏览器不能扩大服务端权限：

- 提供辅助、标准只读和自主三种自主等级，并把选择固定到 TaskRun；
- 允许从终态 TaskRun 创建可追踪的分析分支并并列比较；
- 以追加式 `user.feedback` 事件绑定用户评分、说明及当前 Evidence/Artifact；
- 父分支反馈只作为后续分支的有界规划上下文，不改变工具、数据或审批边界；
- 用浏览器场景覆盖计划确认、反馈提交、父子分支和请求参数。

## 2. 实际交付

### 2.1 自主等级与服务端策略

- `ChatStreamRequest` 增加 `autonomy_mode`；TaskRun 将模式写入现有 `budget_json`，详情和
  SSE `meta` 均返回服务端保存值，不依赖浏览器会话状态；
- **辅助模式**在计划持久化后原子转为 `paused`，追加
  `autonomy.plan_review_requested` 与 Checkpoint；只有用户显式恢复后才开始执行；
- **标准只读模式**在 MCP descriptor 层检查 `read_only`。带写入或外部副作用的工具不会进入
  MCP 执行，拒绝结果以失败 Invocation 和 `autonomy_write_denied` Observation 留痕；
- **自主模式**允许现有低/中风险工具按计划执行，但 `high/critical` 仍必须经过
  ApprovalRecord 请求、用户决定、显式恢复和一次性消费；自主等级不能绕过审批；
- 恢复已有 Run 时只采用持久化模式，客户端不能借恢复请求临时提升权限。

### 2.2 分析分支与反馈闭环

- `/chat/stream` 增加 `parent_run_id`，TaskStore 复用 SQLite v7 已有 `parent_run_id`，无需新迁移；
- 父 Run 必须存在、属于同一项目和对话且已经进入终态；活动 Run、自引用、跨项目和跨对话
  分支均失败关闭；
- TaskRun 详情返回同一对话最近 Run，React 面板只投影当前、父、子和同父分支，展示状态、
  计划版本、自主等级和工具调用数，并可切换到任一分支核对其完整计划、工具证据与反馈；
- 新增 `POST /agent/runs/{run_id}/feedback`。接口要求项目写权限、`If-Match` 和
  `Idempotency-Key`，只接受终态 Run；Evidence/Artifact 引用必须属于该 Run；
- 反馈追加为不可变 `user.feedback` TaskEvent，详情只返回去除主体和控制哈希后的安全投影；
  幂等哈希包含反馈主体，避免不同用户共用 key 时错误重放；
- 创建子分支时最多读取父 Run 最近 10 条反馈和 4000 字符，明确声明反馈不能扩大数据、工具
  或权限范围。
- 修正 LLM Planner 请求边界：有界父分支反馈除参与路由选择外，还会作为最多 24000 字符的
  `planning_request` 进入结构化 Planner payload；它与 contract/context 一样被明确标记为
  不可信规划数据，不能扩大 capability、数据或权限范围。

### 2.3 React 协作体验

- 对话输入区增加三档自主等级选择，并在 `sessionStorage` 中只保存用户偏好；Run 事实仍以
  服务端详情为准，浏览器和未显式传值的 API 请求均默认选择标准只读；
- 辅助模式暂停态使用“确认计划并执行”，与普通暂停的“继续执行”区分；
- 终态 Run 可提交“有帮助/需改进”和补充说明，前端提交前重新读取状态版本，并自动绑定
  当前工具审计中的 Evidence/Artifact；
- 终态 Run 可输入新目标创建分支；请求携带当前自主等级和父 Run，完成后协作面板切换到
  新 Run，并显示相关分支对比；
- Compose 报告流程显式选择自主模式，避免默认只读模式放行写 Artifact 的报告工具。
- Compose 浏览器主链路现继续提交父 Run 反馈，以辅助模式创建 LLM Planner 分支，确认计划后
  执行只读画像；随后切换标准只读模式请求报告，并验证所有 `generate_report` Invocation
  失败、出现 `autonomy_write_denied`、没有成功步骤且报告 Artifact 数不变；模型 fixture 只
  暴露有界布尔/计数审计，用于证明反馈标记到达 Planner，不返回 prompt 正文。
