## 1. 阶段目标

阶段 6 会持续增加数据角色、质量、统计、预测、多数据集与受控并行能力。扩展前必须先建立
运行边界：一个 TaskRun 从创建到终态只能使用创建时经过 Host 准入的 capability/tool 目录，
不能因为注册表、MCP `tools/list_changed` 或部署 profile 在运行中变化而让计划无审计漂移。

6A-1 建立不可变目录和消费边界；6A-2 在该边界上接入受治理目录换代和部署 profile
可用性。两者都不新增分析算法、并行执行或重型依赖。

## 2. 6A-1 实际交付

- SQLite schema v9 新增 `capability_catalog_snapshots`。TaskRun 创建时在同一事务内保存唯一、
  内容 hash 标识、应用与数据库触发器双重保护的不可变目录；readiness、迁移校验、受保护回滚
  和工作区备份/恢复行数清单同步升级；
- `AgentToolRegistry` 从单源 MCP Tool descriptor 生成 `chatbi-capability-catalog-v1`：固定
  capability、tool name、service route、tool version、完整 contract hash、风险、权限、Artifact
  后置条件和只读/幂等属性；目录顺序确定，可稳定计算内容 hash；
- 新 TaskRun 原子绑定当前目录。v9 前创建且尚未结束的兼容任务在首次恢复时只允许补写一次，
  后续禁止替换；SSE `meta` 暴露 snapshot ID 与 content hash，便于审计和恢复核对；
- Planner、澄清后的重新规划和 Observation Replanner 都读取 TaskRun 固定的 capability 列表；
  模型可见工具同时按固定 tool name 集合过滤。注册表新增工具不会进入运行中的任务，只对新任务
  生效；
- 恢复时逐项核对已冻结工具是否仍存在，以及 service route、tool version、contract hash 和
  capabilities 是否一致。缺失或漂移会以稳定 `capability_catalog_drift` 失败关闭，不允许模型
  心算、静默换工具或用新目录覆盖旧目录。

## 4. 6A-2 实际交付

- 官方 SDK Session 的消息缓冲同时接收标准 `notifications/tools/list_changed`；项目内 MCP
  Server 宣告 `tools.listChanged=true`。Gateway 收到通知后重新执行完整 `tools/list`，逐项
  比对 Host 静态 allowlist、输入/输出 schema、capability、风险、权限、Artifact 后置条件与
  版本 hash；缺失、未知、重复或漂移目录以 `mcp_catalog_drift` 失败关闭，不能动态接纳第三方
  或未审查工具；
- 每个新 TaskRun 在写入不可变 snapshot 前必须完成全部远端 Server 发现。快照新增实际验证过的
  分服务目录 hash；目录不可连接时返回可重试 `capability_catalog_unavailable`，契约漂移返回
  不可重试 `capability_catalog_drift`。运行宿主持续监听目录通知，但已创建 TaskRun 仍只消费
  自己冻结的 capability/tool 集合；
- 新增 `AGENT_CAPABILITY_PROFILES`，只接受 `stats`、`forecast`、`browser`、`gpu` 的精确、
  无重复清单，默认 `stats,browser`；GPU RAG 部署会自动投影 `gpu` 已启用。统计能力和浏览器
  截图能力在对应 profile 未启用时携带 `allowed=false`、`required_profile` 与稳定
  `profile_not_enabled` 原因；
- 预测 profile 目前尚无受治理 Forecast Tool，因此无论是否启用都不伪装可执行：禁用时标记
  `profile_not_enabled`，启用后标记 `tool_unavailable`。GPU 当前是知识检索运行加速 profile，
  没有虚构独立 Planner capability；其启用状态与关联能力列表仍进入快照供运维审计；
- Planner 与 Replanner 保留完整目录作为解释上下文，但确定性校验和工具暴露只接受
  `allowed=true` 的 capability/tool。能力缺失会产生明确失败或受约束重规划，不允许退回模型
  心算。
