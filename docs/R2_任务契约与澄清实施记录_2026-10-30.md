## 接口与执行决定

1. 新任务显式冻结 analysis schema v2，保存当前原文哈希、长度、操作及原文位置、
   disposition、参数和 revision。旧 v1 严格读取；未知版本和损坏投影不能回退到宽松解析。
   当前、禁止、暂缓、仅描述、未要求与撤回分开；撤回按字段及参数对象，不按操作家族连带撤销。
2. 当前请求中的完整 AND 条件必须保留。未解析残余和不支持的操作不能静默丢弃。
   引号和已知字段的字面范围与意图词分开，字段 `组别`、`平均收入` 不产生禁止或均值要求。
   同类多步骤不因 capability 相同而去重；超过计划步数上限失败关闭，不截掉后续义务。
3. 一项明确操作对应一次工具调用及一个步骤。筛选、去空、去重不得合并或替换。
   共用执行准入与完成验证：按成功调用、参数哈希、同 run Evidence、结果哈希、
   R1 有效投影和登记的派生 Dataset 逐步推进。旧版本、错误顺序或无关成功不能完成要求。
   变换读取自己的合法父版本；最终回答及报告仍须使用对应最终范围，不能以此豁免旧数据结论。
4. 分组、指标、聚合方法与总计分槽。月份 time 列与 dimension 均可合法分组；
   ID、布尔、类别不能自动当连续指标。总计既要有当前版本正确指标的 sum Evidence，
   也必须实际交付。纯总计不凭空制造用户分组义务，可复用现有两种求和工具入口。
5. 聚合工具的 `sort`、`limit` 是已有展示参数，必须合法且不能改指标或方法；
   行截断不改变工具全量总计。`count` 只按现有工具的指定列非空语义处理，不能冒充全行记录数。
6. 统计“口径”不自动制造知识检索义务。明确查询须有本轮精确对象的成功检索调用；
   相似名称、附录或旧 run 的成功不能替代。禁止和改口按对象保持；多个查询各有独立步骤。
7. 澄清复用前端 `answer_schema.enum`。后端校验槽、候选、任务、计划版本、数据版本、
   resume token、revision 和合同哈希；答案与新版合同同事务写入，失败整体回滚。
   回答只修对应槽，保留其他操作、筛选与总计；不能把单词答案重新编译为整个任务。
   正常恢复读取持久合同；进程崩溃后的新自动恢复策略不在本批，既有失败关闭保持。
8. 全原文的显式比较符与有限中文比较词使用同一归一规则，并检查操作归属。
   换行、分号不能代表撤回条件；无法唯一归属时要求完整条件澄清，不猜 AND。
   闭合示例和引号仅用于请求结构，不能豁免回答中的业务事实数量。
9. 描述“去重会删除的多余记录数”不授权变换；当前执行动作和其后的数量说明分别归属。
   “未做筛选”的原文范围不能扩到同段统计、吞掉总体基数。聚合方法只来自当前聚合片段，
   “回答清洗后行数”不能将原求和改为 count。
10. 明确 `按 <semantic_key> 汇总` 的命名指标依赖保存在对应操作的 `definition_key`，
    复用已有定义键校验，实际数据字段同名时优先识别为字段。澄清不得删除该依赖。
    计划使用既有 `knowledge.definition.resolve`，普通知识检索不能占用该步骤。
    准入和最终重放必须看到本轮真实定义调用、当前数据版本、唯一的定义身份/版本/公式哈希，
    以及与实际数据调用完全一致的编译参数哈希；不能根据想执行的参数反向挑选定义版本。
    模型自选 `as_of` 的历史查询可以只读执行，但本批没有用户版本选择槽，因此不能授权计算。
    只有工具默认时间解析的唯一受控定义可授权命名指标执行。知识请求的外置提问谓词只在
    请求编译时拆分；实际工具查询仍按完整对象匹配，引号内名称不被删改。
11. 条件覆盖审计复用既有 Artifact/Dataset/Memory 的完整资源标识符词法，不把
    `analysis_id=…` 等引用当作业务比较。词法从既有引用消费者下移共用，权限和存在性
    校验仍由原会话解析器执行；词法识别本身不授权访问。真实 schema 中覆盖完整赋值左值
    的字段优先，不能只凭 `id` 子串判碰撞，也不能屏蔽引用旁边的另一个业务条件。
    本批不改写 R4 的指代、记忆或会话恢复算法，不声称覆盖任意未知字段的自由文本歧义。

## 明确的能力边界

- 现有工具按列值分组，不会将日级日期转换为月。已有月份列可分组；原生日级时间分桶
  必须明确澄清为已有列值或保持不支持，不以逐日汇总代替按月。
- 工具聚合仅支持 sum/mean/count。明确最大值、最小值、中位数等要求不能默认为 sum；
  本批不添加新计算方法。
- 按组统计所有记录数与列非空数不同。未支持的全行计数保持未解决，不能删除澄清或
  自动选择唯一数值列制造成功。明确合法字段的非空计数复用既有 count。
- 多个不同聚合方法超出单聚合槽时保持澄清，不能用最后一个方法抹掉前一个要求。
- 自动先查询定义再填充缺失分组/指标/方法未在本批实现。明确槽与受控定义一致可执行；
  定义要求 mean 而冻结要求为 sum 时保持阻塞，不自动改槽，也不忽略定义。其原始能力诊断失败保留，
  后续若恢复自动衔接须先定义可信投影、冲突处理与版本选择合同。
- “检测异常，再排除这些行”的结果依赖除行尚缺已冻结的行引用契约；不能猜测排除行。
  此已知能力回退单列延期，不能把它描述为只有测试夹具变化。
- 复杂自由语言、不确定字段角色、所有少见格式、任意图表数量和崩溃自动恢复不在本批
  扩成通用功能。具体剩余失败须逐项归因，未知核心风险不得直接延期。
