# 交接合成样例

四个CSV均为75行、5列，纯合成数据；不是实际节目、设备、人员或销售记录。全部月度指标采用相同数值，便于业务语义对照，但必须选择各自工件，不能跨场景借证据。

| 文件 | 双条件筛选 | 指标 |
|---|---|---|
| broadcast.csv | 频道=A、状态=已播出 | 播出时长（分钟） |
| device.csv | 设备=A、状态=运行 | 停机时长（分钟） |
| activity.csv | 活动类型=A、状态=完成 | 活动时长（分钟） |
| sales.csv | 渠道=A、状态=完成 | 销售额（元） |

顺序：上传75行；双条件筛选38行；在衍生数据上单独去掉指标空行37行；再按整行去重36行。按月份求和得到75/135/195/255/315/375，完整数据总计1350。每月6条记录满足当前小群体阈值。记录ID为标识符，不应作为连续度量；记录数不能自动称为去重人数。

原始免费完整链上传的是同内容XLSX；这里另提供便于检查的CSV，CSV仍需在用户真实模型实测时记录实际上传结果。文件哈希和预期见oracle.json。无付费命令或凭据包含在样例中。
